# WordWise

WordWise is an Android academic vocabulary learning application designed
for university students who use English as an additional language.

The application will provide short vocabulary review sessions, immediate
feedback, spaced repetition, offline learning and progress statistics.

## Project Status

Phase 1: Initial Android project setup.

## Planned Features

- Academic vocabulary review sessions
- Dictionary API integration
- Offline word storage
- Spaced-repetition scheduling
- Learning statistics
- Adjustable difficulty and session length
- Accessibility and privacy controls

## Planned Technology

- Kotlin
- Jetpack Compose
- Material Design 3
- Navigation Compose
- Room
- Retrofit
- Hilt
- Preferences DataStore
- JUnit and Compose UI testing

## Requirements

- Android Studio
- Android SDK 26 or later
- Internet connection for vocabulary synchronisation

## Running the Project

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronise.
4. Run the application using an Android emulator or physical device.

## Data and Privacy

WordWise is designed to store learning progress locally. It will not
require an account or collect personally identifiable information.
